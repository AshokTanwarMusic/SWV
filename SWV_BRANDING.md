# SWV branding pass

This copy of BitChord 1.5.2 has been rebranded for the SWV application without changing the Android package/namespace identifiers, so runtime IPC, deep links, preferences, and native JNI bindings remain compatible.

Changed: launcher/app label, launcher/adaptive/notification/in-app logo assets, localized user-facing branding, settings footer links, replay/export branding, download folder name (with legacy folder discoverability), backup export name/tag (with legacy import support), user-facing metadata strings, and exact app log/user-agent identity strings.

Upstream license/copyright and necessary internal identifiers are intentionally preserved.
